# agilex3_soc_control_card
Agilex 5 SoC based control card for an AC in/out lab power supply.
The original board used an Agilex 3 FPGA and had a few bugs in the pin connections, so this second revision
uses an SoC instead of just an FPGA. The target is a Linux-capable control board with an Ethernet connection.

Main features:
- Agilex 5 E-Series SoC A5EB013B (quad-core HPS), B23B 795-ball package, -6S speed grade
- 1 GB LPDDR4 (SK hynix H9HCNNN8KUMLHR-NME, 2 channels x16 = x32), 2133 MT/s on the HPS EMIF
- 16 GB eMMC (KIOXIA THGAMVG7T13BAIL, 8-bit, HPS SD/MMC)
- 128 Mbit QSPI configuration flash (ISSI IS25WP128-RHLE)
- 1 Gb Ethernet (Realtek RTL8211FDI RGMII PHY, HanRun HR911130A MagJack)
- muxed ADC block (ADS7056)

Controls power electronics, so it mostly does generic I/O for PWM and SPI/SDM ADCs.
Built by JLCPCB (8-layer, JLC08161H-3313 stack-up).

The LPDDR4, eMMC and QSPI flash are parts shared with the Agilex 3 card and the Efinix Ti135 board, see
`SHARED_PARTS.md`.

## Status

- **LPDDR4 routing: done and tuned (2026-10-31).** All 54 nets (U7 bank 3 to U12) are routed and delay-matched
  with KiCad's time-domain tuner against the Altera 821801 budgets (`LPDDR4_DELAY_REPORT.md`, generated by
  `tools/lpddr4_delay/delay_report.py`):
  - byte spreads 4.5 / 8.8 / 4.5 / 3.3 ps (target 10 ps), DQ-DQS -4.5 ... +8.8 ps (limit -68 ... +43 ps);
  - DQS and CK P/N within 0.1 ps (limit 1 ps), CA/CKE/CS 415.0-417.7 ps die to ball (CK + 10 ps target);
  - no LPDDR4 DRC items, including the 0.2 / 0.3 mm crosstalk spacing rules.
  - IBIS simulation of the routed copper (`sim/lpddr4_si/results/routed.md`): every eye passes at 1600 MT/s
    (typ/min/max corners) and 2133 MT/s (typ).
  - Quartus (`LPDDR4_SWIZZLE_PLAN.md`): the routed pinout and swizzle fit, and a 2133 MT/s build (the -6S
    maximum) meets timing. 2133 MT/s is the design rate.
- Still open: Ethernet PHY routing after the MagJack change, eMMC and HPS peripheral routing, zone refill
  (`NEXT_STEPS.md`).
